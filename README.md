# ARCADE BATTLE

Retro arcade fighting game in a single HTML file. Plays in the browser, on desktop and mobile — no installation needed.

**Play:** https://YOUR-USERNAME.github.io/arcade-battle/

## Controls
- **Arrows**: move
- **Up**: jump
- **Space**: punch
- On mobile: on-screen touch buttons

## Run locally
Just open `index.html` in any modern browser.
